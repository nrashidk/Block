🎮 Core Gameplay (Block Blast Foundation)
The base remains the same — drag and drop tetromino-style blocks onto a grid, clear rows/columns to score points. But here's how to expand it massively:

🆕 New Block Types & Items
Special Blocks

Bomb Block — Clears a 3x3 area when placed
Lightning Block — Clears an entire row AND column
Rainbow Block — Acts as a wildcard, fits any shape
Freeze Block — Locks adjacent blocks in place temporarily
Mirror Block — Reflects its shape horizontally/vertically
Ghost Block — Can overlap one existing block
Multiplier Block — Doubles points for the next clear
Magnet Block — Pulls nearby blocks to fill gaps automatically
Chain Block — Triggers a combo if placed next to another Chain Block
Drill Block — Bores through a full column, removing one block per row
Sticky Block — Merges with adjacent blocks of the same color to form mega-clears

Obstacle Blocks (make it harder)

Stone Block — Requires 2 clears to remove
Ice Block — Must be cleared twice (cracks first, then breaks)
Locked Block — Needs a key item to unlock
Virus Block — Spreads to adjacent cells if not cleared in time
Anchor Block — Cannot be moved once placed
Corrupted Block — Randomly swaps positions with nearby blocks

🌐 Online Multiplayer Modes
1v1 Battle Mode

Both players share a mirrored board; clearing rows sends "garbage" blocks to your opponent

2v2 Team Mode

Teammates share a power-up pool and can send helpful blocks to each other

Battle Royale (up to 50 players)

Last player standing wins; the grid shrinks over time
Eliminated players can spectate with reactions

Co-op Puzzle Mode

Two players work on the same board together to beat a high-score target

Blitz Tournament

Timed 3-minute rounds, bracket-style elimination
Weekly scheduled tournaments with prize pools

Ghost Race

Race against a recording of another player's run in real-time
